# 项目范围

## 项目定位

Retail Agent 是一个面向学习和求职展示的电商 AI 客服项目。它展示在线应用、知识检索、业务
Agent、离线模型训练和 GPU 推理服务如何协作，但不冒充真实电商平台或生产级高可用系统。

## 已交付的纵向闭环

```text
Vue → FastAPI → 会话服务 → 政策闸门 / RAG / Agent 工具 → OpenAI 兼容模型
                         ↓
                       MySQL

公开数据 → 清洗脱敏 → 固定切分 → QLoRA → 行为评测 → vLLM + LoRA API
```

当前版本包含：

- Vue 3 聊天页面、FastAPI API、多轮会话和 SSE；
- MySQL、SQLAlchemy、Alembic 与失败时不留下半条对话的事务边界；
- Milvus Lite、BGE Embedding、BM25、RRF、BGE Reranker 和来源引用；
- 订单/物流查询与退款申请工具，以及参数校验、客户隔离、幂等和审计；
- 固定的检索、Agent、NLU、实体和模型行为评测；
- 公开数据版本、许可证、脱敏、按来源切分和哈希清单；
- Qwen3-4B 的 QLoRA 训练、纠偏实验和可复现实验记录；
- vLLM 加载基础模型与 LoRA，并提供 OpenAI 兼容接口；
- 确定性政策闸门，阻止模型编造当前知识库不存在的期限、金额和承诺；
- 自动化测试、前端构建和 GitHub Actions CI。

## 验收标准

- 三个 Python 模块的测试与 Ruff 检查通过；
- Vue 测试和生产构建通过；
- 本地 API 能创建会话、聊天、查询历史并返回知识来源；
- 工具只能操作当前客户数据，退款申请可幂等重试；
- 未知平台政策不调用 LLM，不返回虚构数字；
- 训练数据、配置、指标和已知失败均可从仓库追溯；
- GPU 机器上的 `/v1/models` 与 `/v1/chat/completions` 已验证。

## 明确不宣称完成

- 没有接入真实订单、支付、物流或资金退款；
- 公开购物对话是澄清案例，不是权威平台规则库；
- 小型固定评测不能代表线上准确率；
- 尚未完成 AWQ、GPTQ 或 GGUF 量化及前后性能对比；
- 两台设备当前没有网络路由，因此 Mac 应用到 GPU 服务的跨设备联调暂缓；
- 未实现多租户、高可用、模型注册平台、灰度发布或大规模监控。

## 后续工作触发条件

量化只有在能够记录量化前后显存、首 token 延迟、吞吐和行为回归时再做。跨设备联调只有在两台
设备处于可互通网络或建立可信 VPN/SSH 通道后再做。除此之外不再扩展抽象层，先完成 GitHub
发布、演示视频和简历材料。

## 数据边界

仓库只提交公开许可数据的处理结果、自编或合成业务数据以及实验报告。API Key、数据库密码、
真实用户资料、模型权重、LoRA 权重和运行时数据库不得提交到 Git。
